BatteryINFO – Smart BMS Monitor

BatteryINFO is an Android application designed to monitor and manage Bluetooth-enabled Battery Management Systems (BMS).

The application connects to compatible BMS devices using Bluetooth Low Energy (BLE), providing real-time battery information, monitoring, logging, history tracking, and supported control features.

✨ Key Features

🔋 Live Battery Monitoring

- View battery voltage and current.
- Monitor battery temperature.
- Track State of Charge (SOC).
- View available battery parameters and cell information.
- Monitor charging and discharging activity.
- Access additional telemetry reported by compatible BMS devices.

📡 Automatic Bluetooth Connection

- Automatically search for saved BMS devices.
- Reconnect to previously paired devices.
- Simplify repeated device connections.

🔗 BMS Pairing

- Discover nearby compatible Bluetooth BMS devices.
- Connect to supported battery management systems.
- Manage device connections.

📊 Battery History

- Review previously recorded battery information.
- Track battery activity over time.
- View available historical battery records.

📝 Live Data Logs

- Monitor incoming BMS communication.
- Observe real-time battery data updates.
- Inspect available communication and diagnostic information.

⚙️ Battery Control

- Access supported BMS control commands.
- Password-protected control interface.
- Explicit confirmation before sending write commands.
- Access control functions supported by the connected BMS.

Warning: BMS control operations can modify battery protection and operating settings. Incorrect commands or configurations may damage equipment or create safety hazards. Only use these functions when you understand their effects.

🔋 Multi-Pack Support

- Discover multiple battery packs when supported.
- Monitor available information from multiple BMS devices.
- View battery information independently for supported packs.

🎯 Purpose

BatteryINFO provides a convenient interface for monitoring battery performance, tracking battery activity, understanding battery conditions, and accessing supported BMS functions from an Android device.

Whether you are checking battery status, reviewing historical information, inspecting live communication, or accessing supported BMS controls, BatteryINFO brings important battery information together in one application.

⚠️ Compatibility

- Requires an Android device with compatible Bluetooth hardware.
- Requires Bluetooth Low Energy support.
- Requires a compatible BMS device and communication protocol.
- Available monitoring and control functions depend on the connected BMS.
- Multi-pack functionality depends on BMS and application support.
- Not every BMS exposes the same battery parameters or control commands.

BatteryINFO does not guarantee compatibility with every BMS manufacturer or model.
